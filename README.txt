RAKTOKO PRO - HTML + Tailwind CSS Landing Page

ISI FILE
- index.html: landing page responsive dengan Tailwind CSS CDN.

SEBELUM DIPUBLIKASIKAN
1. Buka index.html.
2. Ganti nomor WhatsApp contoh 6281234567890 dengan nomor bisnis Anda, format internasional tanpa tanda +, spasi, atau strip.
3. Ganti https://domainanda.com/ pada canonical, og:url, dan domain lain dengan domain website yang sebenarnya.
4. Siapkan gambar preview sosial berukuran 1200 x 630 piksel. Unggah ke hosting, lalu ganti URL https://domainanda.com/images/preview-rak-minimarket.jpg pada og:image dan twitter:image.
5. Ganti nama RAKTOKO PRO jika nama merek perusahaan berbeda.
6. Pastikan klaim ongkir gratis dan perakitan sesuai ketentuan bisnis yang benar.

CARA MELIHAT
- Klik dua kali index.html untuk membuka di browser.
- File memakai Tailwind CSS CDN, jadi koneksi internet diperlukan untuk memuat styling.
- Untuk website produksi, disarankan menggunakan build Tailwind CSS agar aset lebih optimal.

SEO & OPEN GRAPH
- Meta title, meta description, canonical, robots, Open Graph, dan Twitter Card sudah disertakan.
- Open Graph preview biasanya baru bisa diambil crawler setelah halaman dan gambar tersedia secara publik di hosting.
